## 偏振光学实验

原始数据、处理代码、输出图和 A4 打印图集都在 [`偏振光学实验/`](偏振光学实验/) 下。

### 实验内容

1. **马吕斯定律**（[马吕斯定律_数据处理与作图.ipynb](偏振光学实验/马吕斯定律_数据处理与作图.ipynb)）
   - 验证 $I = I_0\cos^2\alpha$
   - 将 $I/I_0$ 对 $\cos^2\alpha$ 作线性拟合，检查斜率 $\approx 1$、截距 $\approx 0$、$R^2 \to 1$

2. **1/2 波片**（[半波片_数据处理与作图.ipynb](偏振光学实验/半波片_数据处理与作图.ipynb)）
   - 验证检偏器转角 $\beta$ 与波片转角 $\theta$ 满足 $\beta = 2\theta$

3. **1/4 波片**（[四分之一波片_极坐标作图.ipynb](偏振光学实验/四分之一波片_极坐标作图.ipynb)）
   - 用极坐标图判断偏振态：线偏振光经 1/4 波片后，45° 入射得到圆偏振光，20° 入射得到椭圆偏振光

### 输出文件

- `图*.png`：各实验的线性拟合图、折线图与极坐标图
- [偏振光学实验_图集.pdf](偏振光学实验/偏振光学实验_图集.pdf)：A4 打印版，每页两张图并附图注，可直接打印
- [make_figures_pdf.py](偏振光学实验/make_figures_pdf.py)：把 PNG 重新排版生成图集 PDF；增删图或修改图注只需编辑其中的 `FIGURES` 列表

## 地磁场测量实验

原始数据、处理代码和输出图在 [`地磁场测量实验/`](地磁场测量实验/) 下。

### 实验内容

1. **磁阻传感器磁电转换特性**（[磁阻传感器_磁电转换特性_数据处理与作图.ipynb](地磁场测量实验/磁阻传感器_磁电转换特性_数据处理与作图.ipynb)）
   - 表 11-1：励磁电流 $I=-300\sim300$ mA，磁感应强度 $B=-6\sim6$ Gs，传感器输出电压 $U$
   - 作 $U$–$B$ 散点图并线性拟合 $U = K B + U_0$，由斜率求灵敏度、截距求零点残余
   - 结果：$K = 0.2509 \pm 0.0013$ V/Gs，$U_0 = 6.5 \pm 4.8$ mV，$\mathrm{Adj.}\ R^2 = 0.99968$

2. **磁阻传感器方向特性**（[磁阻传感器方向特性_数据处理与作图.ipynb](地磁场测量实验/磁阻传感器方向特性_数据处理与作图.ipynb)）
   - 表 11-2：传感器与磁场夹角 $\alpha = 0^\circ\sim90^\circ$（每 10°），输出电压 $U$
   - 作 $U$–$\alpha$ 曲线，按余弦规律 $U = A\cos\alpha$ 拟合，检验方向特性
   - 结果：$A = 1.0609 \pm 0.0144$ V，$\mathrm{Adj.}\ R^2 = 0.99195$；中段（30°–80°）读数系统性偏高约 5%

3. **亥姆霍兹线圈轴向磁场分布**（[亥姆霍兹线圈轴向磁场分布_数据处理与作图.ipynb](地磁场测量实验/亥姆霍兹线圈轴向磁场分布_数据处理与作图.ipynb)）
   - 表 11-3：位置 $x/R = -0.5\sim0.5$（每 0.1R）的 $U_x$；用表 11-1 的 $U$–$B$ 关系反解 $B_x$ 测量值，理论值按 $B_0=4$ Gs 乘 $B_x/B_0$ 计算值
   - 作 $B_x$–$x/R$ 图，与亥姆霍兹公式的理论曲线比较
   - 结果：相对误差平均 0.98%、最大 1.27%；归一化后形状与理论最大偏差 0.33%

## 运行环境

- Python 3.11
- numpy、pandas、matplotlib、Pillow
- Jupyter Notebook（打开 `.ipynb` 文件）

```bash
pip install numpy pandas matplotlib pillow jupyter
```

重新生成图集：

```bash
cd 偏振光学实验
python make_figures_pdf.py             # 生成 偏振光学实验_图集.pdf
python make_figures_pdf.py --preview   # 同时输出每页 PNG 预览
```
