# 地磁场测量实验 误差分析

本实验依次完成了磁阻传感器磁电转换特性、方向特性、亥姆霍兹线圈轴向磁场分布和空间磁场分布四项测量。各项结果的一致性（线性拟合 Adj. R² 均在 0.99 以上，轴向分布归一化形状与理论偏差小于 0.4%）说明测量方法可靠；同时也暴露出若干系统性偏差，下面结合实测数据逐项分析。

## 一、误差来源

### 1. 磁阻传感器自身的误差

- **零点失调与温度漂移。** 磁阻电桥四条桥臂不可能完全对称，无外加磁场时输出并不为零。表 11-1 中 B = 0 时仍有 2 mV 输出，拟合截距为 (6.5 ± 4.8) mV。实验过程中电流使线圈和传感器发热，桥路电阻随温度变化，零点会缓慢漂移。
- **磁滞与置位/复位不彻底。** 传感器经历反向磁化后，磁阻元件的磁畴状态不能完全复原，导致同一磁场下正向、反向读数的输出不同。表 11-1 中正、负半轴单独拟合的灵敏度分别为 0.2504 与 0.2445 V/Gs，相差约 2.4%；U(+B) + U(−B) 从 1 Gs 时的 −0.002 V 单调增大到 6 Gs 时的 +0.036 V，正是这种不对称的直接体现。
- **非线性与饱和。** 磁阻元件的电阻–磁场关系只有在一定场强范围内才近似线性。表 11-1 的最大残差为 0.035 V（满量程的 1.2%）；表 11-2 中 30°–80° 的读数系统性高于理想余弦曲线，60° 处偏高 0.049 V（振幅的 4.6%），与"磁场分量较大时传感器响应被压缩"的饱和特征相符。
- **敏感轴未对准。** 传感器的敏感方向由内部磁阻条带决定，与外壳刻线不一定严格一致。在方向特性测量中，这一角度偏差会被误认为转角误差；在空间分布测量中，移动传感器时外壳姿态的微小改变也会改变所测的磁场分量。
- **标定误差。** 用表 11-1 拟合的 U–B 关系把所有电压换算成磁感应强度，斜率 b = 0.2509 V/Gs 的标准误差为 0.0013 V/Gs（0.52%），截距标准误差为 4.8 mV。这部分误差会按比例传递到表 11-3 和空间分布的全部结果中。

### 2. 线圈与磁场方面的误差

- **线圈常数与中心场标定。** 计算理论分布时取中心场 B₀ = 4 Gs（标称值），而实测中心值为 4.043 Gs，相差 1.1%。若实际激励电流与标称值有偏差，或线圈匝数、半径与设计值不同，整个磁场会按同一比例缩放。
- **线圈几何误差。** 亥姆霍兹线圈的均匀性依赖"间距等于半径"这一条件，此时中心处磁场二阶导数为零。若两线圈间距、半径或同轴度有装配偏差，中心附近的平坦区会变窄、场分布发生倾斜，理论曲线也不再严格适用。
- **磁场不均匀与地磁本底。** 线圈内部并非理想均匀场，且实验现场未做磁屏蔽，地磁场（约 0.5 Gs）与附近铁磁物体（仪器外壳、导轨、铁架）产生的杂散场叠加在测量场上，构成难以扣除的恒定或缓变背景。

### 3. 几何对准与读数误差

- 导轨、转台的定位与刻度分辨力有限，传感器位置（0.05R 一格）和转角（刻度 1°）都有读数误差；坐标原点与线圈中心不重合会引入整体平移。
- 数字电压表分辨力为 1 mV，相对于约 1 V 的读数约为 0.1%；表笔接触、读数时刻不同还会带来毫伏级的随机波动。

### 4. 环境与时间因素

线圈电源与放大器在通电后逐渐升温，输出随时间缓慢漂移。这在空间分布的 7×7 逐点扫描中表现最明显：按 y 逐行测量，后两行整体比前几行高 0.3%–1.0%，且 x 越大差别越明显。

## 二、各部分的误差表现

| 测量内容 | 主要指标 | 观测到的偏差 | 主导误差来源 |
|---|---|---|---|
| 磁电转换特性 | K = 0.2509 ± 0.0013 V/Gs，Adj. R² = 0.99968 | 最大残差 0.035 V（1.2% FS）；正反向灵敏度差 2.4% | 磁滞、非线性、零点漂移 |
| 方向特性 | A = 1.0609 ± 0.0144 V，Adj. R² = 0.99195 | 30°–80° 系统偏高，60° 达 4.6% | 传感器饱和、角度读数、敏感轴偏差 |
| 轴向磁场分布 | 相对误差平均 0.98%，最大 1.27% | 归一化形状偏差 < 0.33%；±0.5R 不对称 0.5% | 标定比例、线圈常数、定位误差 |
| 空间磁场分布 | 全场起伏 2.37% | 角点实测 +1.2%，理论应 −1.6% | 读数随时间的漂移、传感器姿态 |

可以看到：凡是只比较**相对分布**的测量（轴向分布的归一化形状），结果都很好（偏差 < 0.4%）；凡是依赖**绝对标定**或**长时间逐点测量**的测量（中心场绝对值、空间分布角点），偏差就升到 1%–3%。这与上述误差来源的划分一致。

## 三、不确定度估算

**1. 磁感应强度 B 的不确定度**

由 B = (U − a)/b，按误差传递公式

u_B = √[ (u_U / b)² + (u_a / b)² + ((U − a)·u_b / b²)² ]

取 U ≈ 1.02 V（B ≈ 4.04 Gs）、u_U ≈ 1 mV、u_a = 4.8 mV、u_b = 0.0013 V/Gs，则三项分别为 0.004、0.019、0.021 Gs，合成得 u_B ≈ 0.029 Gs，相对不确定度约 **0.7%**。标定斜率与截距的误差是主要贡献，电压表分辨力的影响可以忽略。

**2. 方向特性的角度误差**

U = A cos α 对 α 的灵敏度为 dU/dα = −A sin α，故由角度误差 δα 引起的相对误差约为 |tan α|·δα。若转角分辨力为 1°，在 30°、45°、60°、80° 处分别约为 1.0%、1.7%、3.0%、9.9%。因此 α 接近 90° 时，相对误差被急剧放大——这正是 80° 附近读数偏离余弦曲线较大的原因之一；而绝对值本身很小，对整体拟合的影响有限。

**3. 与实测偏差的对照**

- B 的合成相对不确定度 0.7%，与轴向分布归一化后 0.33% 的形状偏差、以及约 1% 的绝对偏差量级相符；
- 方向特性 60° 处 4.6% 的偏差，略大于 1° 角度误差单独造成的 3.0%，其余部分可由传感器饱和与敏感轴偏差解释；
- 空间分布 2.4% 的起伏超过 0.7% 的测量不确定度，说明角点的异常升高主要不是随机误差，而是时间漂移造成的系统误差。

## 四、减小误差的措施

1. **利用置位/复位脉冲。** 每次测量前对传感器施加置位脉冲，消除历史磁化；必要时正、反置位各读一次取平均，可显著减小磁滞与零点偏置。
2. **采用翻转法。** 对线圈电流正、反向各测一次，取两次读数之差的一半，可同时扣除零点残余、地磁本底和邻近铁磁物的恒定干扰。
3. **控制测量时间与温度。** 通电预热至稳定后再开始测量；逐点扫描尽量快，或按"往返各测一遍取平均"的方式抵消漂移；测量期间监测并记录激励电流。
4. **提高对准精度。** 用输出极值法确定 0°（转动传感器找最大读数）和 90°（找最小读数）；在导轨上固定传感器姿态，避免移动时转动。
5. **多次重复与独立标定。** 关键点重复读数取平均；用高斯计或标准磁场对线圈常数和中心场 B₀ 做独立标定，而不是直接采用标称值。
6. **改进数据处理方法。** 对方向特性可先按表 11-1 的校准曲线逐点把电压换算成场强，再进行余弦拟合，从而把传感器非线性与方向特性分离开来；对空间分布可先扣除逐行测量的漂移基线（例如用同一位置的前后两次读数插值），再作曲面。

## 五、小结

本实验的主要系统误差来自磁阻传感器的磁滞、非线性与零点漂移，以及线圈常数和几何对准的不确定；随机误差主要来自电压表与角度刻度的读数。定量估算表明，磁感应强度的相对不确定度约为 0.7%，角度接近 90° 时方向特性的相对误差会显著放大。轴向磁场分布的归一化形状与理论符合到 0.4% 以内，说明相对分布的测量是可靠的；绝对场强与空间分布的角点偏差（1%–3%）则以系统误差为主，可通过置位/复位、翻转法、控制漂移和独立标定加以减小。
